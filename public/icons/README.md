# MyWallet SVG Icon Set

29 editable, scalable SVG icons recreated to match the dark dashboard concept. These are vector recreations, not exact vector extractions of raster artwork.

## Next.js usage
Copy the SVG files into `public/icons/`. Use `<img src="/icons/wallet.svg" alt="Wallet" width="24" height="24" />`.

SVGs use `currentColor`, ideal for inline SVG or SVG components. Note: an SVG loaded via `<img>` does not inherit the surrounding CSS text color; inline the SVG or use a React icon library for dynamic colors.
